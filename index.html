🔢③ 使用验证码

📲3.1 一键复制与 30 秒自动清除功能模块 M-05

功能概述

点击任意令牌卡片即可复制当前验证码，并弹出「已复制」提示。为防止验证码残留在剪贴板被其他应用读取，复制内容 30 秒后自动清空（期间你复制了其他内容则不会被覆盖）。时间型验证码（TOTP）每 30 秒刷新；计数型（HOTP）卡片则点「使用此码」按钮复制当前码并使计数器 +1。

界面示意
284 915点击卡片复制 · 倒计时圆环在卡片右侧
  • 点击卡片 — 整张卡片可点，按下有轻微按压反馈，松手即复制并 Toast「已复制」。
  • 3+3 分组 — 6 位验证码显示为 3+3（如 284 915），8 位显示为 4+4，等宽字体居中，方便逐位核对。
  • 临期变红 — 剩余 ≤10 秒时数字与圆环整体变红（见示意图中 AWS 卡片），提醒你等下一组再复制。
▲ 验证码展示与临期状态示意
操作步骤
  • 先打开需要登录的网站/App，走到「输入验证码」一步。
  • 切回本 App，点对应卡片 → 看到屏幕下方「已复制」提示。
  • 切回网站粘贴 → 提交。建议在圆环刷新后再复制，时间更充裕。
注意事项
  • 30 秒后剪贴板自动清空属正常安全设计，重新点卡片即可。
  • 红色状态粘贴容易「刚好过期」，等它刷新成新数字更稳妥。

🫙4.3 空状态引导功能模块 M-08

第一次使用列表为空时，首页显示大号品牌圆标和「扫码添加 / 手动添加」双入口按钮，跟着引导走即可。筛选无命中时的空态则完全不同：只出现「清除筛选」，不引导添加，避免误会数据丢失。

  • 自动同步：开启「启用云备份」后，每次添加令牌自动加密上传一份新备份（编辑、删除令牌不触发，见注意事项）；

  • 恢复最新：点「恢复最新」一键恢复时间最近的一份；

  • 右上角齿轮随时回到仓库配置页修改名称、仓库、分支、目录或授权。

第四步：JSON 配置导入 / 导出（跨设备迁移仓库配置）

适用场景：换新手机或多台设备使用时，不必逐个重新填仓库、授权——把已配置的仓库导出成一个 JSON 文件，在新设备上一键导入。入口在「添加仓库」弹出框的底部（云备份页 → 点「添加仓库」即可看到「导入 JSON 文件」与「导出 JSON 配置文件」两张卡）。

  • 导出：点「导出 JSON 配置文件」→ 设置口令（默认加密导出，导入时需输入同一口令才能还原；也可打开「以明文导出」开关，会显示红色警告）→ 选择保存位置，生成 qingshu-backup-config.json。文件只包含已授权的仓库及其访问令牌，保证导出的文件可再次导入还原；一个已授权仓库都没有时会提示「没有已授权的仓库可导出」。
  • 导入：点「导入 JSON 文件」→ 选择文件。App 会自动识别文件类型：加密文件会弹出「输入导出口令」框（口令错误会提示重新输入，可直接重试）；普通 JSON 直接解析。解析合并期间有进度提示（读取文件 → 解析 → 合并），完成后 Toast 汇报结果（新增几条、覆盖几条、令牌更新几条）。
  • 导入成功后立即可用：访问令牌随配置一并导入，导入的仓库直接处于「已授权」状态，无需再走授权流程，进仓库页即可备份。

JSON 文件怎么写（自行手工编辑时）——一个数组，每项一个仓库，允许加注释：

[
  {
    "name": "青数官方仓库",   // 显示名称，可省略（省略时显示仓库路径）
    "type": "github",          // 服务商：github / gitee，不区分大小写
    "repo": "owner/repo",      // 仓库路径，必填
    "token": "ghp_xxxxxxxx",   // 访问令牌（PAT），必填
    "branch": "main",          // 分支，省略时默认 main
    "dir": "/qingshu-backup"   // 远端目录，省略时默认 /qingshu-backup
  }
]
  • 覆盖合并规则 — 导入不会全量替换：与现有仓库「服务商 ＋ 仓库路径」相同的条目覆盖原配置（保留原有的启用开关等状态，令牌也按文件为准更新，适合轮换令牌后重新导入）；其余条目作为新增追加；同一文件内重复出现的条目以后一条为准。
  • 容错跳过 — 个别条目格式不对不会导致整体失败：不支持的服务商（仅 github / gitee）、仓库不是 owner/repo 格式的条目会被跳过，并逐条提示「第 N 项：…已跳过」，其余条目正常导入。
  • 安全提醒 — JSON 文件里是明文或口令加密的访问令牌，等同于你仓库的钥匙：建议始终用加密导出；明文文件切勿发到聊天群、网盘等不安全位置。
注意事项
  • 仓库必须保持私有：备份文件虽已加密，也不建议放到公开仓库。
  • 自动同步只在「添加令牌」时触发，编辑、删除等操作不会触发——做了重要变更后请到仓库页点「立即备份」。
  • 移除仓库 ≠ 删除备份：无论在列表行还是配置页移除，都只删除本机配置、本机密码与授权令牌，远端仓库中的备份文件不受影响。
  • 备份密码是唯一解密钥匙，忘记后云端备份将永久无法解密；本机加密记住密码，换机后需输入密码原文。
  • 导出的 JSON 配置文件包含仓库访问令牌，等同于仓库钥匙，请妥善保管；建议使用加密导出。
  • 纯本地模式下云端备份默认关闭；如需使用，可在云备份页打开「允许在纯本地模式下使用云端备份」放行（这是纯本地模式下唯一可恢复联网的功能，开启后可手动备份/恢复，自动同步需另在各仓库页开启）。
  • 云端与本机 .qsc 文件共用同一加密格式，可互相恢复。

🔐 令牌与验证码

如何添加令牌？

点首页右上角「+」，三选一：①「扫一扫」扫描 PC 端二维码（单码自动识别并填入）；②粘贴 otpauth:// 链接后导入；③手动输入账户名与密钥。密钥原文通常只显示一次，请另行妥善保管；录错密钥生成的码不会被网站认可，删除令牌重录即可。

验证码怎么刷新和复制？

点按令牌卡片即可复制验证码。TOTP 每 30 秒自动刷新，卡片右上角圆环为剩余时间；HOTP 为事件型，点「使用此码」复制当前码并使计数 +1。圆环快走完时建议等下一轮新码再输入；复制的验证码 30 秒后自动清空剪贴板（期间复制了其它内容则不覆盖），请尽快粘贴。

令牌多了怎么管理（置顶 / 标签 / 搜索 / 删除）？

编辑令牌时打开「置顶显示」让常用令牌排在最前；设置标签后列表顶部出现标签筛选行，点标签即可筛选；顶部搜索框可按账户名或标签搜索；删除在编辑页中。搜索与标签筛选同时生效（取交集）；删除仅移除本机令牌，已备份的文件不受影响，删除前建议先确认已有备份。

Steam 的验证码不太一样？

Steam 使用专用格式（5 位字母数字）。添加时类型选 Steam；其他网站保持默认 TOTP。

HOTP 验证码对不上了？

HOTP 按次数递增、不看时间，计数错位后最简单的办法是删掉重新扫码添加。

💾 备份与恢复

本机备份怎么做？

「我的 → 云备份」进入「本机 .qsc 文件备份」：首次需设置备份密码，之后点「导出到本机（.qsc）」选择保存位置即可。导出的是那一刻的快照，令牌变化后需重新导出；.qsc 是敏感文件，请存放在可信位置。

云备份怎么同步？

「我的 → 云备份」绑定你的 GitHub / Gitee 私有仓库 → 打开「自动同步」：此后每次添加令牌都会自动加密上传；也可随时点「立即备份」。每次备份都是一个带时间戳的新 .qsc 文件，旧备份不会被覆盖。「自动同步」只在添加令牌时触发，编辑、删除等操作不触发。

如何恢复备份？

本机备份：「我的 → 云备份 → 从本机文件恢复（.qsc）」选择文件并输入备份密码；云备份：进入对应仓库，在备份列表中选任意一份 .qsc 恢复。恢复按密钥去重后合并到本机，已存在的令牌自动跳过，不会覆盖或重复。

怎么确认备份真的可用？

用「从本机文件恢复」试导入一次——已存在的令牌会自动跳过，无副作用；云备份先打开仓库的备份列表，确认最近一次 .qsc 文件存在。导出成功不代表内容正确，试恢复是最可靠的验证手段，建议完成重要录入后验证一次。

忘记备份密码怎么办？

没有任何找回途径。备份密码是唯一解密钥匙，不会保存在远端；本机会加密记住密码方便重复导出，但换机或重装后仍需输入密码原文。请把密码记录在可靠的密码管理器中，忘记后对应备份文件将永久无法解密。

误删了验证器还能找回吗？

有备份就能恢复（见上文「如何恢复备份」）；没有备份只能去对应网站重新扫码绑定。建议定期备份并在换机、删除应用等重要操作前先试恢复验证一次。

🛡️ 安全与隐私

密钥与数据是怎么存储的？

所有密钥经 SQLCipher 加密存储在本机数据库，数据库密钥由系统 Keystore 保护，不经过任何服务器——开发者也看不到你的数据。请自行妥善保管各网站的密钥原文（一般可在网站安全设置中重新生成）；卸载应用或清除数据会删除本机数据库，操作前请先备份导出。

应用锁能保护什么？

防止他人直接打开应用查看令牌。「我的 → 应用锁」开启：设备支持指纹/人脸或锁屏凭据时直接生效，否则需先设置应用锁密码。每次进入应用（冷启动或从后台切回）都要验证，任一通道通过即可。它只是进入门槛，不加密数据本身；解锁后验证码明文显示，公共场合请注意遮挡。

纯本地模式是什么？

让应用彻底不联网，满足极致隐私需求。「我的 → 纯本地模式」开启并确认后，账号等联网入口自动隐藏，云备份默认一并关闭（可在云备份设置中单独放行）。停用：版本更新检查、登录/注册、扫码、时间同步；不受影响：令牌增删改、验证码生成、应用锁、本机备份；该限制只作用于本应用，不影响设备上其它应用。

为什么这个页面不能截屏？

应用锁与令牌页开启了系统级防截图保护，截屏/录屏会被系统拒绝——这是防止验证码被恶意应用偷走的安全设计。

应用锁指纹弹窗没反应？

点一下屏幕即可强制重试；App 内置 15 秒看门狗也会自动复位重发验证请求。

✨ 更多功能

扫码登录是什么？

在 PC 端扫码确认登录，无需输入账号密码：PC 端登录页生成二维码 → 手机打开「扫一扫」扫描 → 在手机上确认登录，全程可随时取消。确认前请核对 PC 端页面显示的账号信息；仅识别二维码类型；纯本地模式下扫码登录不可用。

时间同步是做什么的？

TOTP 验证码依赖准确时间，偏差过大会导致验证码被网站拒绝。「我的 → 时间同步」打开后，弹窗并排显示您的手机时间与网络标准时间（两者同步走字）；相差超过 1 分钟请到系统设置校准手机时间，相差 1 分钟内即可保证令牌正常工作。标准时间取自网络站点，纯本地模式下不可用。

悬浮球是什么？

应用退到后台后，在屏幕边缘保留可拖拽的悬浮徽标，随时快速回到安全中心。「我的 → 悬浮球」开启主开关（需授予「显示在其它应用上层」权限）；「悬浮徽标」子开关关闭后仅保留状态栏常驻通知。点按徽标唤起应用，长按展开快捷面板，拖拽可调整位置；主开关关闭后子开关一并隐藏；不需要时建议关闭以减少常驻消耗。

🚨 三条铁律
1️⃣ 定期备份 —— 手机丢失、损坏、重装时，备份是唯一救命稻草；
2️⃣ 记牢备份密码 —— 忘记密码等于备份作废，建议密码管理器 + 纸质各存一份；
3️⃣ 换机先备份、后卸载 —— 新手机恢复成功并抽查无误后，再动旧手机。
