# 青数安全中心（qsc）使用说明

> 适用版本：`1.0.15`
> 本文档面向普通使用者，介绍 App 各项功能怎么用。

---

## 一、这是什么

青数安全中心是一个 **动态验证码（验证器）App**，可以替代 Google Authenticator 之类的工具，随时生成 6/8 位一次性验证码，用于登录各类网站的二次验证。它同时提供账号注册登录、扫码登录、以及加密备份与恢复功能。

**核心特点**：

- **打开即出码**：验证码在本机生成，不需要登录、也不需要联网。
- **密钥加密存储**：所有密钥用 SQLCipher 加密保存在本机，不会上传服务器。
- **应用锁**：可开启生物识别（指纹/人脸/锁屏密码）保护，防止他人拿手机直接查看。
- **加密备份**：可导出加密备份文件，或备份到你自己的 GitHub / Gitee 仓库，换手机也能凭密码恢复。

> 只要使用「生成验证码」这一个功能，就**不需要登录**。只有在「扫码确认登录 PC 端」和「云备份授权」时才需要账号。

## 二、首页与出码

打开 App 后进入的就是首页（令牌页），底部有三个标签：**令牌 / 帮助 / 设置**。

### 2.1 添加令牌

点击首页右上角的「**+**」，有三种方式：

1. **扫码添加**：对着电脑屏幕上的二维码扫描即可。
2. **粘贴 otpauth:// 链接**：把对方给的 `otpauth://` 链接粘贴进来。
3. **手动输入密钥**：手动填写 Base32 密钥。

> 同一个密钥重复添加会自动去重，不会出现两条重复记录。

### 2.2 查看与使用验证码

- **TOTP（最常见）**：验证码每 30 秒自动刷新一次，卡片右上角的圆环表示剩余时间。**点按卡片即可复制**验证码，粘贴到需要填写的地方。
- **HOTP（事件型）**：不会自动刷新，需要点「**使用此码**」来复制，同时计数器会前进一次。
- **Steam**：Steam 专用格式，固定 30 秒、5 位验证码。

### 2.3 其他操作

- **搜索**：顶部搜索框可按令牌名称或账户搜索。
- **标签**：可给令牌设置自定义标签，方便分类查找。

## 三、注册与登录

> 再次提醒：仅使用验证码不需要登录。注册登录只为「扫码确认登录」等功能服务。

### 3.1 注册

进入「设置 → 登录 / 注册」，选择：

1. 选择验证方式（邮箱或手机）；
2. 点击发送验证码，输入收到的验证码；
3. 填写用户名、密码，提交注册；
4. 注册成功后自动登录。

### 3.2 登录

1. 输入账号（用户名或已验证的手机号）和密码；
2. 若系统要求二次验证，会向你的邮箱或手机发送一条验证码；
3. 输入验证码，完成登录。

> 二次验证只支持邮箱码 / 手机码，验证器本身的动态码不用于此处。

### 3.3 退出登录

进入「设置 → 退出登录」。退出后本机令牌数据会保留，验证码功能继续可用。

---

## 四、扫码登录（手机确认电脑登录）

1. 在电脑端登录页找到二维码；
2. 打开 App 首页的「**扫一扫**」，对准二维码扫描；
3. 手机上会显示**登录来源（网站）**，请核对是否为你本人正在操作的网站；
4. 确认无误后点击「**确认登录**」；如来源陌生或非你本人操作，请点「取消」，谨防钓鱼。

> App **绝不会自动确认登录**，必须由你本人手动点击确认。若二维码来源不在信任范围内，App 会直接拒绝。

如果扫到的是「添加验证器」的二维码，则会自动作为新令牌添加到首页。

## 五、备份与恢复

进入「设置 → 云备份」。

### 5.1 本机备份

- 导出：把令牌导出为一个加密的 `.qsc` 文件，保存到你选择的位置。
- 恢复：选择「从本机文件恢复」，导入 `.qsc` 文件并输入备份密码。

### 5.2 云备份

- 绑定你自己的 **GitHub 或 Gitee** 仓库作为云端保管处（同一个平台可以添加多个仓库）。
- 绑定后，令牌的增删改会自动同步到你的仓库。
- 恢复时从对应入口导入备份并输入密码即可；已存在的令牌会自动跳过，不会重复。

### 5.3 重要提示

- 🔑 **备份密码是唯一钥匙**：密码不会保存在任何远端服务器，也**没有任何找回手段**。一旦忘记，对应备份文件将永久无法解密。请务必把密码记录在可靠的密码管理器中。
- ✅ **导出成功 ≠ 备份可用**：建议导出后立刻用「从本机文件恢复」试导入一次，能成功恢复才说明备份文件完好、密码正确。
- ⚠️ **重要操作前先手动备份一次**（例如更换手机、卸载重装之前）。
- 删除本机令牌**不会**删除云端已保存的历史备份。

## 六、应用锁

进入「设置 → 应用锁」开启。

- 开启后，每次进入 App（或离开约 15 秒后返回）都需要通过**指纹 / 人脸 / 锁屏密码**验证。
- 冷启动时会立即上锁，验证通过前不显示任何内容。
- 关闭应用锁需要先通过设备密码验证，防止他人拿到手机后直接关闭。
- 若手机未录入指纹/人脸，也没有设置屏幕锁定，则应用锁不可用。

> 提示：应用锁是「进门验证」，验证码在屏幕上仍是明文显示，公共场合请注意遮挡。

---

## 七、纯本地模式

进入「设置 → 纯本地模式」开启。

开启后 App **不再联网**：

- 停止版本更新检查与下载；
- 登录 / 注册 / 扫码确认不可用；
- 云端备份默认关闭（如需使用，可在「云备份」设置中单独放行）。

**不受影响**：验证码生成、应用锁、本机文件备份等本地功能照常使用。

> 这是 App 自身的使用限制，不会影响手机上其他应用的网络。

---

## 八、外观与语言

- **外观**（设置 → 外观设置）：可选择多种主题色，以及「跟随系统 / 浅色 / 深色」模式。
- **语言**（设置 → 语言）：支持「跟随系统」、中文、英文。

---

## 九、检查更新

进入「设置 → 检查更新」可手动检查新版本；App 启动时也会自动检查一次。

- 发现新版本会提示下载安装；
- 强制更新时会自动下载（仅 WiFi）并引导安装；
- 如选择「取消」，该版本会被暂时忽略，之后仍可手动检查。

## 十、常见问题

| 问题 | 解答 |
|---|---|
| **如何添加令牌？** | 点击首页右上角「+」：可扫描二维码、粘贴 `otpauth://` 链接，或手动输入 Base32 密钥。 |
| **验证码多久刷新？** | TOTP 每 30 秒刷新一次；HOTP 为事件型，需点「使用此码」复制并使计数器前进。 |
| **验证码怎么用？** | 点按令牌卡片复制验证码，粘贴到需要二次验证的网站即可。 |
| **如何正确备份与恢复？** | 在「备份」页导出 `.qsc` 加密文件，或绑定私有 Git 仓库自动同步；恢复时导入文件并输入备份密码，已存在令牌会自动跳过。重要操作前先手动备份。 |
| **怎么确认备份能用？** | 导出后用「从本机文件恢复」试导入一次，能成功恢复即说明文件完好、密码正确。云端可先查看备份列表确认存在。 |
| **忘记备份密码怎么办？** | 密码不会保存在远端，也无法找回——忘记后备份将永久无法解密。请记录在可靠的密码管理器中。 |
| **应用锁保护什么？** | 每次进入 App（或离开超 15 秒后返回）需生物识别或锁屏凭据验证。它是「进入门槛」，验证码解锁后仍为明文显示，请注意遮挡。 |
| **一定要登录吗？** | 不需要。验证码生成本就在本机完成；只有扫码确认登录、云备份授权才需要账号。 |
| **纯本地模式是什么？** | 开启后 App 不再联网，停止更新检查、登录与云端备份；验证码等本地功能不受影响。 |
| **扫码登录安全吗？** | App 会显示登录来源并要求二次确认，绝不自动确认；来源不可信时会直接拒绝，请务必核对网站后再确认。 |

## 十一、使用建议

1. 首次使用先添加常用网站的验证器令牌。
2. 添加完成后，**立刻做一次本机备份**，并存好备份密码。
3. 如注重隐私，可开启「纯本地模式」。
4. 公共场合建议开启「应用锁」，并注意遮挡屏幕上的验证码。
